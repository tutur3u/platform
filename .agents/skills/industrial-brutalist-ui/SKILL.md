# Industrial And Swiss-Grid Interfaces

For a requested industrial direction, use a disciplined grid, sharp typographic
hierarchy, utilitarian color, and selective monospace metadata. Draw from technical
print or terminal interfaces without adding fake telemetry or decorative jargon.

Thin grid dividers can use a contrasting parent background with a small CSS gap.
Use semantic structures for actual data and commands: tables or description lists,
`kbd` for shortcuts, and `output` for results. Preserve reading order and responsive
reflow even when the visual grid is rigid.

Texture, scanlines, stamped labels, or high-contrast type are optional accents.
Keep them out of the way of text, focus rings, and interaction. Preserve the brand's
existing tokens where required and choose available, licensed fonts and assets.
Avoid motion that impairs readability; support reduced motion and usable static states.

Verify narrow layouts, text scaling, contrast, keyboard access, and real interaction
states. A distinctive aesthetic should still make the user's task easy to complete.
