# Design Catalog

Use the bundled search tools to answer a concrete design question. Preserve existing design tokens unless redesign is requested. Generate a full design system only for work that needs one.

Read `references/workflow-guide.md` for the relevant commands and examples.
Search its headings for the current operation; do not load the entire catalog for a small task.

Run bundled scripts and templates from the skill directory so their relative paths resolve.
