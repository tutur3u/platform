# Interaction patterns

Reviewed abridgment of upstream patterns.md.

Choose roles and keyboard behavior together. Roving focus has one tab stop;
active-descendant navigation keeps DOM focus on the owning control. Selection
and focus are separate states. Reordering uses stable item identities, draft
movement, explicit commit and cancellation. Restore focus when an item moves or
disappears. Check disabled items, boundaries, Home/End and directionality.
