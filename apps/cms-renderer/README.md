# CMS renderer

TanStack Start + Void + Vite+ Worker. The synthetic first-site fixture is never a production fallback. Unknown hosts, missing published pointers and unsupported schemas fail closed.

Rex builds locally from the exact reviewed PR head and deploys the emitted `dist/server/wrangler.json`. CI runs afterwards and is not on the deployment path. This lane never deploys. Configure `CMS_DELIVERY_ORIGIN` as the HTTPS origin of the current live external-projects delivery API. The adapter calls `/api/v1/workspaces/{workspaceId}/external-projects/delivery` without preview or authentication parameters. It accepts `publishedPageVersion` with either the service-read `data` snapshot or the Rust `blocks` snapshot and maps both to the shared versioned block contract. An absent binding returns 409; missing snapshots return 404. The live HTTP owner must attach the service-role published-only read from the data contract; the pre-extension live response has no snapshots. Mutable legacy blocks never substitute for a published snapshot.

Configure `CMS_SITES` as a hostname-keyed JSON object. Each site supplies `id`, `workspaceId`, `defaultLocale` and optional `tokens` (`foreground`/`background` hex colors and `font`: serif, sans-serif or monospace). Domain admission belongs to the deployment owner; this is not a self-service domain verification API. Do not route a domain before its ownership is verified.

Entries use full public-path slugs: `home` for `/`, `en` for `/en`, and `en/about` for `/en/about`. Languages remain separate entries. Entry `metadata.description` and `metadata.ogImage` provide page SEO; entry `title` supplies title and OG title. Confirm those paths with the content owner before cutover. Content porting is outside this lane.

The cache key contains site ID, normalized path, locale and immutable version ID. Published delivery responses use a 30-second CDN TTL and HTML uses a 30-second edge TTL. Configure `CMS_PURGE_TOKEN` through the secret manager. A publish hook can POST `{ "path": "/", "locale": "vi", "version": "previous-version-id" }` to `/__cms/purge` on the site host with `Authorization: Bearer <CMS_PURGE_TOKEN>`. Authorization hashes both supplied and expected bearer values to fixed-size SHA-256 digests and compares them with `timingSafeEqual`. The hook registration belongs to the publishing owner and is not wired by this source change. Version-key changes independently avoid serving the old HTML after delivery refreshes.

`bun run build` generates the route tree, then `bun run type-check` validates it. The admitted CI artifact job runs focused renderer/SDK checks and records a bounded emitted-config receipt. PR execution requires a non-draft PR with the `ready-for-ci` label. It has no secret build inputs; any public Supabase build input must come from `vars.PRODUCTION_SUPABASE_URL`. No credentials, live records, custom hostname or production route are included.

The Vite config defines `process.env.NODE_ENV` as `"production"` in the server environment. The Worker startup assertion runs before the server handler loads and refuses any other mode. `workers_dev` and `preview_urls` are false; `start-bridge.config.ts` sets `unknownHost: 'reject'` and the request path enforces that policy against the configured site hosts. CF-2's shared production startup helper replaces the local assertion after its exact head is relayed.

The publisher resolves the purge origin from trusted workspace/site configuration matching a `CMS_SITES` host; `CMS_DELIVERY_ORIGIN` is the backend origin and must not be used as the purge origin. Capture the previous published pointer before atomic publish, then purge its version using the confirmed `{path,locale,version}` body.

Six additional pure components (Section, Heading, Gallery, VideoEmbed, Accordion and Divider) are available for synthetic previews. Their props are explicitly defined in `packages/cms-blocks/src/render/fixture-types.ts`; they are not accepted by the public page codec or registered in the editor. Replace those fixture types with the editor-owned schema contract before public registration.
