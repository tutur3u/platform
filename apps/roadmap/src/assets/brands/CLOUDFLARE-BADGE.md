# Cloudflare web badge

`cloudflare-protected-badge.png` is Cloudflare's official "Protected by
Cloudflare" web badge, byte-for-byte as published in Cloudflare's press kit
(https://www.cloudflare.com/press-kit/, "Website badges",
`BDES-5287_ProtectedByCloudflareBadge_web_badges_5.png`, 761×264).

Cloudflare's trademark guidelines (https://www.cloudflare.com/trademark/)
let Cloudflare customers use these web badges to tell visitors that their
site is protected and accelerated by Cloudflare, and ask that they are not
altered in any way (no stretching or recolouring). Any other use of
Cloudflare's logos needs Cloudflare's written permission, so this page
shows the badge (served from this Worker, never hotlinked) and names
Cloudflare in text elsewhere.

Keep the file unmodified and render it at its own aspect ratio only.
