This reference reflects the checked-in manifests and lockfile for maintained workspaces. It describes the versions Tuturuuu uses, rather than asserting that every dependency is the newest upstream release. A package range is not a deployed version. Install with the pinned Bun version and `bun install --frozen-lockfile`; release artifacts and deployment evidence establish what is running. Rust/TanStack Start are paused and excluded from refreshes.
