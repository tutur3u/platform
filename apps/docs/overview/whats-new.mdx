User-facing changes merged to the platform, grouped by area. Each entry links to
the public pull request. Security hardening, infrastructure and internal tooling
are not listed here. Entries are listed when merged; web changes roll out per
environment and mobile features arrive with app releases, so a change may not
be available to you yet. Availability still depends on the app, workspace
permissions and access flags; see the [product directory](/platform/applications/overview).

First edition covers 17 to 31 October 2026.

## Meet

- Better transcription quality and support for solo meetings ([#7267](https://github.com/tutur3u/platform/pull/7267)); see [Meet](/platform/applications/meet).

## Mobile

- Education mode and a Today classes card ([#6982](https://github.com/tutur3u/platform/pull/6982)).
- The task quick actions sheet is redesigned ([#6974](https://github.com/tutur3u/platform/pull/6974)), and you can set or clear task dates from it ([#7079](https://github.com/tutur3u/platform/pull/7079)).
- The board timeline is a day agenda ([#6981](https://github.com/tutur3u/platform/pull/6981)).
- The inventory item list is rebuilt with scan and search ([#6976](https://github.com/tutur3u/platform/pull/6976)); see [Mobile](/platform/applications/mobile).

## Tutoring and Contacts

- Tutor groups for the policy, a teacher picker and queues ([#7054](https://github.com/tutur3u/platform/pull/7054)).
- A workspace campus list and an announcement place picker ([#7049](https://github.com/tutur3u/platform/pull/7049)).
- Per-session content and class time appear in the parent message ([#7055](https://github.com/tutur3u/platform/pull/7055)).
- Pick an existing topic contact in the add-contact form ([#7047](https://github.com/tutur3u/platform/pull/7047)); see [Tutoring](/platform/applications/tutoring) and [Contacts](/platform/applications/contacts).

## Mail and Tasks

- A tighter inbox list hierarchy and density in Mail ([#7146](https://github.com/tutur3u/platform/pull/7146)), and the inbox list loads without waiting on bootstrap writes ([#7144](https://github.com/tutur3u/platform/pull/7144)).
- Initiatives are hidden in Tasks and their create controls removed ([#7099](https://github.com/tutur3u/platform/pull/7099)).
