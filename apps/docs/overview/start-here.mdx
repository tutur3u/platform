publishing, AI assistance, and developer tooling into a shared account ecosystem.
Start with the task you want to accomplish. Availability depends on the app,
workspace permissions, access flags, account eligibility, and configured providers.

## What is active

The maintained application path uses Next.js Web and satellite apps, shared
TypeScript packages, hosted Supabase, and the owning hosted/Worker services.
The Docker cron runner is retired. Docker setup, the Rust backend, and TanStack
Start are not in use and are not required to learn, develop, or operate the live
Next.js products. Their retained source is historical or future-resumption
material. TanStack **Query** is still the active client data library; it is
separate from the paused TanStack **Start** frontend.

## Read product claims correctly

A public marketing page explains a product; it does not grant access to its
private workspace data. A source route describes an implementation; it does not
prove deployment or entitlement. Research surfaces and vision documents are
identified separately from supported workflows. For source-derived versions,
use the [version reference](/reference/repository/versions); for the version a
browser is actually serving, use its platform build metadata.
