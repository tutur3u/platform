Forms (`forms.tuturuuu.com`, `apps/forms`) owns the complete form product:
builder, studio, respondent experience, responses, analytics, and its form APIs.
Web redirects legacy form destinations to this app.

## Create, review, and share

1. Open `/{wsId}/forms` in an authorized workspace.
2. Create a form at `/{wsId}/forms/new`, then edit its structure and content in
   `/{wsId}/forms/{formId}`.
3. Configure questions, validation, layout, access, and sharing. Preview the
   respondent flow before sending the link.
4. Share `/f/{shareCode}` or use the embed tools. A protected form can still
   require login; possession of a URL is not a universal access grant.
5. Review responses and analytics in the private studio.

Share-link creation and lookup are scoped to the workspace in the request path:
a form that does not belong to that workspace returns `404` and no share link is
read or created for it.

The current question catalog includes text and typed inputs, choices, rating
and scales, NPS, ranking, and presentation blocks. The precise question types,
validation behavior, response formatting, and analytics rules are in
[Forms: question types, embedding, SEO, and collaboration](/platform/features/forms-embedding-and-seo).
Use [Studio layouts](/platform/features/forms-studio-layouts) for layout and
editing behavior.

Author rich text in titles, descriptions and choices renders through one
`sanitize-html` allowlist on the server and in the browser: headings,
paragraphs, lists, emphasis, links, code, rules and images, plus `alt`,
`href`, `rel`, `src`, `target`, `aria-*` and `data-*`. Links keep http(s),
ftp(s), mailto, tel, sms, callto, xmpp, matrix, cid and relative URLs; `data:`
is allowed only on images. Script, event and style attributes are removed.
SVG, MathML, iframe, object, embed, template and form-control content is dropped
with its whole subtree. Coverage: `apps/forms/src/features/forms/rich-text-html.test.ts`.

## Embedding and search

The SDK is delivered at `/embed.js`; the embedded route is
`/embed/{shareCode}`. Embed wrappers are noindex and distinct from the canonical
respondent page. The author's SEO controls can override title, description,
social image, canonical, keywords, and noindex on a shared form. Public shared
forms retain this existing opt-out behavior; protected or unavailable forms
keep their access-aware metadata. Private studio and response data stay noindex.
Forms are not enumerated into a public sitemap from workspace records.

## Collaboration and data

Studio presence/broadcast uses private form channels. Forms tables live in the
private database schema and are accessed through authorized server logic.
Respondent state, submissions, protected content, and studio access must stay
separate. Reopening a shared form can restore the signed-in respondent's own
state; this does not expose another respondent's answers.

[Forms route reference](/reference/repository/routes/forms),
[Search indexing](/platform/features/search-indexing), and
[Forms feature details](/platform/features/forms-embedding-and-seo) provide the
implementation and behavior contracts.

## Native Start candidate

Generate the native entrypoints with
`node scripts/start-bridge-codemod/cli.mjs forms --apply`. Marked generated
files are maintained by this codemod. The App Router pages, layouts and
server actions use the shared RSC adapter; route handlers compile in its
RSC environment so their server-only imports keep the same boundary.

Run `bun run --cwd apps/forms type-check:cloudflare` for the native type
check and `bun run --cwd apps/forms build:cloudflare` for the real Vite+
build on an admitted build host. The retained `build` script continues to
serve the current publisher until an explicit cutover-preparation PR.

Browser qualification must use a host matching the shared locale cookie domain.
The canonical domain uses a Secure cookie; an HTTP loopback browser drops it and
can fall back to English after a locale redirect. A fixture may relay the sealed
loopback Worker at the canonical HTTPS browser origin while preserving Cookie
and Set-Cookie. Assert the real locale cookie, `lang=vi` after hydration, and
actual EN/VI heading markup in the SSR response; status 200 and metadata alone
are insufficient.

The native publication admits only `forms.tuturuuu.com` and the custom staging
host `<app>.staging.tutur3u.com`. Apex `/forms`, workers.dev and unknown hosts
are rejected before app dispatch. Apex admission remains a separate cutover.
The app-owned `start-bridge.config.ts` supplies the nonce CSP and response
headers. Non-assets force private, no-store caching, including removal of CDN
cache overrides. Static files retain their cache policy only for successful
GET/HEAD responses without HTML or cookies.

Normal pages deny framing. The existing `/embed/{shareCode}` exception, stays framable by third-party sites and noindex; its CSP keeps
the same script nonce and changes only frame ancestors. This preserves the
retained Next publisher's `framablePathPatterns: ['embed/[^/]+']` policy in
`apps/forms/next.config.ts`. Locale-prefixed embed URLs retain the default
framing denial; the SDK uses the bare `/embed/{shareCode}` URL. The host, caching and
framing contracts are covered by
`apps/forms/src/runtime/response-security.test.ts`. Final acceptance requires
the exact sealed artifact, public and authenticated browser checks, and an
immediate rollback before canonical publication.

For a future `/forms` admission, middleware uses Web's shared Supabase session without refreshing,
exchanging or clearing satellite sessions. Legacy session-writing endpoints
return 409 on that mount; host-root authentication keeps its existing behavior.
Anonymous share/embed pages and shared-form reads and submissions remain public;
their route-level access, Turnstile and rate limits still apply. Private page
loaders and API handlers validate the actor and workspace access. These mount
and anonymous-respondent cases are covered by
`apps/forms/src/proxy-refresh.test.ts`.

The native Worker also preserves the platform's canonical uploaded WebGL
framing exception. Those proxied responses keep the upstream sandbox and framing
headers, remain private/no-store and noindex, and do not use the embed policy.
Composed bridge-and-wrapper tests cover WebGL documents, child assets and
neighbouring paths. The ordinary `type-check` command checks both the retained
app and `tsconfig.cloudflare.json`, so hosted native qualification covers the
router, Start entry and generated adapters as well as emitted bindings.

## Share-link management

Share-link management requires `manage_forms` and membership in the form's own
workspace, including when an existing link is returned. The share-link route
tests cover workspace ownership and valid existing links. Public form access
continues to follow the published form and share-link rules.
