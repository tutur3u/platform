## Usage

Language helps you view everything on [Tuturuuu](https://tuturuuu.com) in your preferred language.

### Supported Languages

Currently, we provide first-class support for the following languages:

- **English**
- **Vietnamese**

### How to Change Language

[Tuturuuu](https://tuturuuu.com) detects your browser's language automatically. To choose one yourself, open the account menu from your avatar and pick **Language**: **English**, **Tiếng Việt** or **System**.

- Picking a language stores it in the shared `NEXT_LOCALE` cookie, so every Tuturuuu app on the same domain follows it.
- **System** removes that choice. The app then follows your browser's languages again (`Accept-Language`), falling back to English.
- The menu marks the stored choice, or **System** when there is none, whatever locale the current URL shows.
- After a change the page loads again as a full document at its address without a `/en` or `/vi` prefix. A locale prefix outranks the cookie, and only a document load lets each app's proxy negotiate the language; a client refresh on the native Start runtime cannot.

Scope: Web, Workspace, Nova and every satellite app's account menu (`LanguageDropdownItem` and `SystemLanguageDropdownItem` in `@tuturuuu/ui`). Colab keeps its own locale store with the same three choices. Coverage: `locale-preference.test.ts`, `language-dropdown-item.test.tsx` and `language-toggle.test.tsx` under `packages/ui/src/components/ui/custom/`.

<Note>The language switcher is only available after you have logged in.</Note>

### Contribute

If you want to help us translate [Tuturuuu](https://tuturuuu.com) into your language, feel free to open a pull request on our [GitHub repository](https://github.com/tutur3u/platform).

Each supported locale lives in a single message bundle under `apps/web/messages/`:

- `apps/web/messages/en.json` for English
- `apps/web/messages/vi.json` for Vietnamese

When you add or change a key, update it in **both** `en.json` and `vi.json` so the bundles stay in sync, then run `bun i18n:sort` to keep the keys ordered consistently before committing. `bun i18n:sort` expands short inline arrays onto several lines; run `bun oxc:write` on the bundles you changed afterwards so the diff holds only your keys.
