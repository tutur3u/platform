Profiles and workspace memberships support identity and collaboration. Tasks, calendar activity, time records, shared content and learning activity support the features people choose to use. Preferences, usage information and security events support product operation and abuse prevention. Some content is shared only when a feature or its owner enables sharing.

See the [personal data inventory](/platform/data-protection/inventory) and [data protection standard](/platform/data-protection-standard) for scope, rights and retention limits.
