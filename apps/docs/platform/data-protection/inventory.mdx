## Evidence boundary

This register describes repository source at `8d6a13e58762aedff6b1ea5eabb6de474a257e99`. It uses [generated Supabase types](https://github.com/tutur3u/platform/blob/8d6a13e58762aedff6b1ea5eabb6de474a257e99/packages/types/src/supabase.ts), [migration history](https://github.com/tutur3u/platform/tree/8d6a13e58762aedff6b1ea5eabb6de474a257e99/apps/database/supabase/migrations), owning routes, service code and checked-in Cloudflare configuration. It does not query production, inspect secrets, replay migrations or verify deployed grants, provider settings, backups or data volumes. A source definition is not evidence that a store is deployed or populated.

The schema census contains **655 tables and 6,932 columns**. The appendices include all candidate tables, including catalogs that may contain no personal data. Every row lists all generated `Row` columns, its inventory family and source evidence for policy declarations. Free text, JSON, content, embeddings and indirect identifiers require review even when a column name does not mention a person.

- [Private schema](/platform/data-protection/schema-private).
- [Public schema](/platform/data-protection/schema-public).
- [Storage schema](/platform/data-protection/schema-storage).

Each appendix row inherits its family's purpose, current lifecycle and rights-path assessment below. The policy index reports declarations found in migration text, not effective privileges. Dynamic SQL, schema moves, inherited/default grants, security-definer RPCs and later policy changes need applied-schema verification in an isolated fixture. An unresolved entry is an explicit access-coverage gap, not a claim that the table is public or inaccessible.

The source includes both active API routes and retained legacy implementations behind generated wrappers. Links to legacy implementations identify current behavior where the active wrapper delegates there. The inventory does not authorize changes to paused runtimes.

They do not prove subject discovery, physical object removal or processor erasure. `private` normally routes through privileged server RPCs and application authorization, while `public` can have direct RLS paths. ## Reproduce and maintain the inventory

Use source-only searches and generated types. Never read credential files or query production to refresh this page. The appendices describe their extraction and policy-index limits. Useful bounded searches are:

```bash
rg -n '^  [a-z_]+: \{|^    Tables: \{|^        Row: \{' packages/types/src/supabase.ts
rg -n 'CREATE POLICY|create policy|ENABLE ROW LEVEL SECURITY|enable row level security|REVOKE|GRANT' apps/database/supabase/migrations
rg -n 'storage.buckets|bucket_id' apps/database/supabase/migrations
rg -n 'deleteUser|on_delete_user|cleanup_ai_studio_retention|retention_days|expires_at' apps/database/supabase/migrations apps/web/src packages/ai/src/memory
rg -n 'durable_objects|kv_namespaces|r2_buckets|queues|d1_databases' apps --glob '*wrangler*.jsonc'
rg -n 'durableObject|queue|r2Bucket|kvNamespace' apps --glob '*cloudflare.config.ts'
```

Future changes must update both the owner family's lifecycle and the store row. The [delivery plan](/platform/data-protection/delivery-plan) requires isolated applied-schema RLS/grant tests before those source declarations become acceptance evidence.

The following source-only Python census reproduces table and column counts without importing runtime code or accessing a database. It reads every generated table rather than selecting only likely PII column names.

```python
import collections
import pathlib
import re

text = pathlib.Path("packages/types/src/supabase.ts").read_text()
rows = []
schema = None
in_tables = False
in_row = False
for line in text.splitlines():
    match = re.match(r"^  (\w+): \{$", line)
    if match:
        schema = match[1]
        in_tables = False
    if line == "    Tables: {":
        in_tables = True
    if line in ("    Views: {", "    Functions: {"):
        in_tables = False
    match = re.match(r"^      (\w+): \{$", line)
    if match and in_tables:
        table = {"schema": schema, "name": match[1], "columns": []}
        rows.append(table)
    if line == "        Row: {":
        in_row = True
    if in_row and re.match(r"^          \w", line):
        table["columns"].append(line.strip().split(":")[0])
    if line == "        };":
        in_row = False
print(collections.Counter(row["schema"] for row in rows))
print(len(rows), sum(len(row["columns"]) for row in rows))
```
