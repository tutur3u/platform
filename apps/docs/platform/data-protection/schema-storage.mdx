## How to read this appendix

This source census contains 10 `storage` tables and 89 columns at `8d6a13e58762aedff6b1ea5eabb6de474a257e99`. It includes non-personal catalogs as candidates. See the [inventory](/platform/data-protection/inventory) for each family's data category, purpose, current retention/deletion path and export/erasure coverage. All generated `Row` columns are listed so indirect identifiers, free text and JSON are not hidden by a name filter.

The access column indexes migration declarations by table name, including prior schema locations. A declaration is evidence to inspect, not a certified effective grant. It does not evaluate predicates, policy drops, schema moves, dynamic SQL, default grants, RPC privileges or RLS bypass. `Not indexed` means unresolved. Private tables normally use server capabilities, but this appendix does not assume that every private table has identical privileges. Applied-schema negative tests are a phase-2 gate.

For reproducible counts, use the source-only census command on the inventory page. Table GRANT/REVOKE links show up to two recent distinct literal declarations, including their original schema. These are not resolved effective privileges. Policy links come from literal `CREATE POLICY` and `ALTER TABLE ... ENABLE/DISABLE ROW LEVEL SECURITY` statements in lexically ordered migration files. The latest matching RLS declaration and up to three recent distinct role/action declarations are shown with their original schema. SQL links also identify the first and last migration mentioning the table token when no policy was indexed. This is a conservative review index, not a SQL interpreter.
