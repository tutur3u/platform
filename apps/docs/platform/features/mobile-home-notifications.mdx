---
title: Mobile Home and Notifications
description: Layout, grouping and state rules for the mobile Home dashboard and the Notifications inbox
---

Home and Notifications use the grouped design language of mobile Settings:
muted captions above rounded grouped cards, Lucide line icons in tone-tinted
tiles, and theme tokens only. Data sources, actions and routes did not change
with the redesign.

## Home

- **Header.** Today's date, a time-of-day greeting with the profile display
  name when one is set ("Good morning, Linh"), and the workspace switcher: a
  scrolling row of workspace chips followed by **More**. The shell navbar
  keeps the "Home" title, so the greeting is not a second page title.
- **Workspace chips.** With fewer than five workspaces, every workspace has a
  chip. From five on, the chips are the user's pinned workspaces in pin order,
  led by the current workspace when it is not pinned. Tapping a chip switches
  the current workspace, as the picker does. **More** lists the workspaces
  without a chip, then Find workspace (the existing picker and its search),
  Edit pinned workspaces (from five workspaces) and New workspace. From five
  workspaces, a long press on a chip (or its screen-reader action) pins or
  unpins it. Pins are stored per user, not per device, in the
  `MOBILE_PINNED_WORKSPACES` user config through `/api/v1/users/me/configs`.
  They are fetched only from five workspaces, and edits wait until the stored
  pins have loaded, so a failed load never overwrites them. A failed load
  retries after 2, 8 and 30 seconds and again when the app resumes. A failed
  save restores the previous pins, and the Edit pinned workspaces checkboxes
  follow what is stored, not the tap. Chip pills are 44dp tall with 48dp
  touch targets, and long names ellipsize inside a chip while the row
  scrolls.
- **Widgets.** The existing widgets keep their order, visibility and
  **Customize Home** editor. The tasks widget shows two sections: **Today**
  (overdue first, then due today) and **Up next** (later due dates), up to
  three tasks each without repeats. The calendar widget is **Calendar** (timed
  events in the next seven days). Mail, meetings, finance, notes and the Today
  summary follow. Each section is a caption with a **See all** (task and
  calendar sections) or **Open** link above one grouped card. Widget IDs did
  not change, so saved Customize Home layouts carry over.
- **Task rows** show the due state first: Overdue (destructive tone), Today
  (warning), Tomorrow (primary) or the localized date, then board and list.
  **Event rows** show a calendar-leaf date tile, weekday and time.
- **States.** First loads show placeholder rows inside the card. Failed loads
  show an inline "Something went wrong / Pull down to try again." row. Empty
  widgets show an inline message with the widget's icon.
- **Responsive.** Page kind `root`. Widgets flow in content-sized columns of
  at least 340dp: one column on phones, two on portrait tablets and up to
  three on laptops and desktops. The header puts the switcher beside the
  greeting from 560dp of content width.

## Notifications

- **Grouping.** The inbox and archive are grouped by device-local calendar
  day: **Today**, **Yesterday**, **Last 7 days** and **Earlier**. Groups keep
  the server's newest-first order; an out-of-order item starts a new group
  instead of being moved.
- **Rows.** Each row has a type tile (invites warning, security and rejections
  destructive, completions and approvals success, mentions and mail info), a
  primary unread dot on the tile, a semibold title while unread, the body (up
  to three lines), then the workspace and relative age. Open invites show
  **Decline** and **Accept**; answered invites show a status badge. A
  48dp read toggle sits at the trailing edge.
- **States.** First loads show placeholder rows; load failures and empty tabs
  show a centred message, with **Retry** on failures. Raw error text is never
  shown.
- **Responsive.** Page kind `detail`: full width on phones and a centred
  readable column (600dp on tablets, 720dp on desktops). A notification opens
  its destination route, so the list does not use a list-detail split.

## Calendar reminder alerts

Mobile local calendar reminders show the event name in the title and the
localized lead time plus occurrence date/time in the body. English and Vietnamese
omit the timezone label by default for both timed and all-day events. Timezone
resolution and clock conversion remain unchanged; all-day reminders show only
the occurrence date. This rule applies to mobile scheduled OS alerts, not the
server-backed inbox or attendee emails, which do not use this formatter. Task
reminder copy is unchanged.

Regression coverage: `test/features/reminders/reminder_notification_copy_test.dart`
checks both languages, the Asia/Saigon alias, date-only all-day copy and a timed
occurrence projected into a different calendar day.

## Regression coverage

- `test/features/shell/view/appearance_root_tabs_render_test.dart` (parts
  `home_render_cases.dart` and `notifications_render_cases.dart`) renders both
  screens in the real shell with fixture data at 390x844, 820x1180 and
  1440x900 in Classic light/dark, a gradient and a blob theme. It asserts the
  phone gutter, the column count, the 44dp targets, the four group captions,
  and the loading, error and empty states. Set `SETTINGS_RENDER_DIR` (plus
  `SETTINGS_MATERIAL_FONT` pointing at a Roboto TTF, and optionally
  `SETTINGS_RENDER_PIXEL_RATIO`) to write PNG captures.
- `test/features/notifications/widgets/notification_day_groups_test.dart`
  covers calendar-day bucketing and feed-order preservation.
- `test/core/layout/grouped_rows_test.dart` covers tones, row targets and
  state actions.
- `test/features/dashboard/view/home_workspace_chips_test.dart` covers the
  chip rules (all chips below five workspaces, pins in order led by an
  unpinned current workspace, stale pins skipped), switching, the More menu,
  pinning per user, failed-save rollback and 2x text at 320dp. The render
  cases above assert the Today, Up next and Calendar sections and screen-reader
  activation of More and See all.
