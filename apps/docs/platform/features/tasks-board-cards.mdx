---
title: "Tasks board cards"
description: "Inline task IDs on board cards and overdue tasks staying in their own list"
---

## Scope and default

This applies to task cards in the shared board UI used by Web and Tasks:
Kanban and List cards on member, project and public boards. It changes no task
data or permissions.

## Task IDs

A card shows its ID before the title, as `[DEV-248] Title`, in the title's own
color. There is no separate ID chip. The title button's accessible name reads
the same `[DEV-248] Title`, so screen readers announce the ID.
A task whose only project gives it that ID shows no project badge, since the
ID already names the project; a task in several projects keeps its badges, and
a project without a key keeps its badge because there is no ID. Cards in a
Documents list show no ID, so they keep their project badge too.
Cards in a Documents list keep their existing omission of the ID. The row above
the title appears only for selection, the document badge and the external-source
badge, and is absent otherwise.

## Overdue tasks

Kanban has no Overdue or Upcoming columns. An overdue task stays in its own
list and keeps its red corner and red due date. A card on an open board
re-checks its due date every minute, so it turns overdue without a reload.
Done and closed tasks, and tasks with no due date, never turn overdue and do
not re-render on that clock.

Saved board layouts and pins that still list the Overdue or Upcoming columns
are read without them; nothing needs migrating.

## Exceptions

Personal external task snapshots keep their source breadcrumb.
