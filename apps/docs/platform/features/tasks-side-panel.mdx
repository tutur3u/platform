## Scope and default

On a board, opening an existing task shows it in a panel docked to the right
edge instead of a centered dialog. The board leaves room for the panel and stays
usable: clicking another card swaps the panel's task, X or Escape closes it, and
Expand switches to the focused dialog. The panel reuses the task dialog content
(header, title, details tabs, description); its header actions wrap under the
title instead of clipping at the panel's width.

This applies to the shared board UI used by Web and Tasks.

## Exceptions

Only task edits opened while a board view is mounted use the panel; read-only
and public boards keep the dialog. Creating a task keeps its create
presentation, documents keep their document presentation, and drafts stay
fullscreen. The panel is not a saved presentation preference.
