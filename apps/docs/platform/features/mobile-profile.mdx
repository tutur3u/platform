Profile is a mobile root dock destination. It shows only the signed-in
user's own identity and personal, user-filtered activity. The activity
Timeline is a separate screen opened from Home. Neither screen shares
activity with anyone else.

## Profile

Scope: the mobile app's Profile root tab (`/profile`). Profile is one of the
two screens whose top bar carries the workspace picker; Home is the other.

From top to bottom, Profile shows:

- **Identity.** The avatar, the display name, the email and the bio, with an
  **Edit profile** button that opens the profile editor
  (`/settings/profile`). Identity from a previous account is never shown
  while the current one loads. Signed or private avatar URLs are never
  cached to disk.
- **Focus Time.** Task-linked tracked time for Today, This week and This
  month in compact units ("1h 5m", "45m"), with **See all** opening the
  Timer statistics. It loads from the user's verified personal workspace
  only and never requests a workspace-wide aggregate. A failed load shows an
  inline message with **Retry**.
- **Switch account.** The most recent other saved accounts and the newest
  one's email. It opens the account switcher, which also adds and manages
  accounts.
- **Quick links.** Settings, Appearance, Notifications, Security and
  devices, Help and feedback, and About.
- **Sign out and Delete account.** Sign out asks for confirmation first.
  Delete account opens the public account-deletion page in the in-app
  browser, like the Settings row.

The profile banner is edited in Edit profile and is not displayed on
Profile. Pull to refresh and re-selecting the Profile dock item reload the
profile and Focus Time.

## Timeline

Scope: `/timeline`, opened from the Timeline action in Home's top bar. Its
dock shows Back, All and Today; Back is not counted among the dock's items.

- **Days.** Activity is grouped by calendar day in the device time zone,
  newest day and newest item first, under a header that stays pinned while
  its rows scroll.
- **Rows.** Each row shows the time, a source tile on the day's rail, and a
  card with the title and a source pill. Rows whose source has a destination
  open it on tap, also from screen readers, and every row card is at least
  48dp tall.
- **Filters.** Source chips (Tasks, Calendar, Finance, Notes) narrow the
  loaded activity to one source; tapping the selected chip shows every
  source again. Today shows today only, All clears the day and source
  filters, and Search narrows by title. Filters never change what is
  fetched.
- **Paging.** Without a filter, the next page loads as the end comes into
  view. With a filter active, pages load only from **Load more**, so a
  narrow filter never walks the whole history on its own. A spinner shows
  while any page loads.
- **States.** First loads show skeleton rows. Empty, filtered-out and
  unavailable timelines show a state message; a failed load offers
  **Retry** unless access was refused. Pull to refresh reloads the first
  page.

- `test/features/profile/view/profile_sections_test.dart`: quick links,
  sign-out confirmation, the account-deletion row and the switch-account
  preview.
- `test/features/profile/view/profile_focus_time_test.dart`: Focus Time
  figures, See all, reload on dock re-select, and the bio.

  `profile_timeline_coverage_test.dart`: day grouping across UTC and DST
  boundaries, pinned headers, incremental deduplicated paging, filtered
  Load more, row semantics and 320px at 3x text.

  Timeline action opens `/timeline`.
- `test/features/shell/view/shared_navbar_large_text_test.dart`: the
  Profile title and the 44dp workspace picker in the real shell navbar.
- `test/features/profile/profile_goldens_test.dart`: Profile and Timeline
  goldens in classic and Sorbet, light and dark, on phone and tablet.
