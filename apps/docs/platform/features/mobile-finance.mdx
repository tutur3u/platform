## Primary action

Each Finance list puts its most-used action in the floating dock's priority
slot, because people add records far more often than they search:

| Screen | Primary action |
| --- | --- |
| Overview | New transaction |
| Transactions | New transaction |
| Wallet | New transaction in that wallet |
| Budgets | New budget |
| Wallets | New wallet |

Search is a top-bar icon on Transactions and Wallets (Overview's search opens
Transactions in search). The action is only offered with the matching
permission. Where the dock has no room for it (narrow phones with every
destination shown), the shell shows it as a filled top-bar button instead.

## Destinations

The dock holds Overview, Transactions, Budgets and Wallets; More opens
Categories and Checkpoints. Finance has no separate Manage page: creating a
wallet belongs to Wallets, and old `/finance/manage` links open Wallets.
Overview also opens All-wallet check directly.
Coverage: `finance_manage_redirect_test.dart` and `app_registry_test.dart`.

## Periods

Transactions and a wallet page pin a period bar: previous, the period, next
(never past today) and a Week / Month / Year chooser. Finance managers can also filter Transactions by
tag. Both open on the current
month; Transactions also offers All time, which search uses. Weeks start on
Monday.

## Empty transactions

The empty message follows what hides the rows; the period alone never counts
as a filter:

- Nothing in the period: "No transactions in {period}" with Add first
  transaction.
- Kind, category, tag or wallet filters hide every row: "No matching
  transactions" with Clear filters, which keeps the period.
- A search query matches nothing: "No results for {query}" with Clear search.

## Wallet page

A balance card (with a workspace-currency estimate for foreign wallets and the
credit limit for credit wallets) offers Transfer and Edit. Below the balance, Reconcile opens the wallet's
balance review and the checkpoint timeline opens its recorded checks. Below
the pinned period bar, the period's income, expense and net
keep their labels on one line at any supported width and text size; amounts
shrink to fit rather than clip, and the figures stack when three columns would
be too narrow. A daily in/out chart (monthly for a year) appears once every
row of the period is loaded. Transactions follow, grouped by day with each
day's net.

## Wallet reconciliation

Enter the observed balance to preview the signed variance against the wallet
ledger. Save reviewed balance records a checkpoint without changing
transactions. When a check uses a different date or time, its saved details
show the server-calculated historical variance.

Open a checkpoint in the timeline to compare the observed and ledger balances.
People with transaction-create permission can post a non-reporting adjustment
for the checkpoint or for an unresolved interval between two checks. The server
calculates the adjustment from the current ledger and skips it when the
difference is zero. Wallet-update permission controls recording, editing and
deleting checks. Each check uses its wallet's currency.

All-wallet check records several observations at one time. Its vertical list
opens the relevant wallet, and the amount-visibility control masks variances as
well as balances. The focused `wallet_checkpoint_ui_test.dart` covers signed
balance inputs, variance direction and light and dark renders.

## Budgets

Each budget shows its health (on track, near limit, over), what is left and
what can still be spent per remaining day, counting today. Tapping a budget
opens its details; Edit is offered with budget permission.

## Recurring transactions

Overview opens recurring transactions, with each rule's frequency, wallet and
next scheduled date. Finance managers can create, edit or delete rules. Use a
negative amount for an expense and a positive amount for income. A rule uses
the selected wallet's currency and can end on a date.

## Hidden amounts

The eye toggle masks every figure on these screens, including balances,
totals, day nets, budget meters and per-day allowances. The wallet chart is
omitted while amounts are hidden, since bar heights would reveal relative
sizes.

Regression coverage: `finance_redesign_test.dart` (label fit at 320 dp and
1.3x text, empty-state variants, wallet masking, period and budget-pace
rules), `finance_accessibility_test.dart` (create in the dock, search in the
top bar, masking on every screen) and the Linux goldens in
`finance_goldens_test.dart`.

## Parity with web Finance

Compare the native mini app with the standalone web Finance dashboard in
`apps/finance/src/app/[locale]/(dashboard)/[wsId]`, its shared UI in
`packages/ui/src/components/ui/finance`, and the mounted APIs in
`apps/finance/src/app/api` and `packages/apis/src/finance`. The entry in
`apps/web` links to standalone Finance.

| Feature | Web Finance | Mobile Finance |
| --- | --- | --- |
| Overview | Balances, income and expense, category and balance trends | Balances, workspace-currency estimate, monthly cash-flow chart and recent activity |
| Wallets | List, detail, create, edit, delete, credit and interest tools | List, detail, create, edit and delete. Dedicated interest tools are open |
| Transactions | List, detail, create, edit, delete, attachments, confidentiality and reporting preferences | Core transaction lifecycle, attachments, confidentiality and reporting preferences |
| Categories | Create, edit, delete and migrate | Create, edit and delete. Migration is open |
| Tags | Manage workspace tags and assign them to transactions | Create, edit and delete tags in Categories. Assign tags to transactions |
| Budgets | Create, edit, delete and track category budgets | Create, edit, delete, detail, status and daily spending pace |
| Transfers | Linked wallet entries with source and destination amounts | Create and edit transfers, including cross-currency amounts. Linked entries collapse in activity |
| Recurring transactions | Schedule and manage recurring rules and view upcoming entries | List, create, edit and delete rules. Next dates appear in the list |
| Invoices | Create and manage invoices, subscriptions, fee locks and reporting | Open |
| Reports and charts | Balance trend, cash flow, category breakdown and invoice analytics | Monthly overview and wallet-period cash flow. Dedicated reports are open |
| Wallet checkpoints | Record observed balances, batch check, history and transaction adjustments | Inline wallet review and timeline, checkpoint and interval adjustments, compact all-wallet check |
| Multi-currency | Wallet currencies, exchange rates and converted workspace totals | Wallet currencies, exchange rates, converted workspace totals and amount masking |
| Filters and search | Text search plus wallet, category, tag, creator, date and transaction type filters | Text search, wallet, category, tag, type and period. Creator and arbitrary date ranges are open |
| Exports and imports | Transaction export, Money Lover import and invoice spreadsheet exports | Open |
| Debts, promotions and inventory reconciliation | Dedicated web workflows | Open |

Mobile requests use the Finance repository and its bearer-authenticated endpoint
mappings. Verify routes and response contracts before adding a new client call.
