The Tuturuuu citation helper lives at `/cite` in `apps/web`. It accepts a DOI,
ISBN, source URL, or manual fields and formats a reference-list entry and an
in-text citation. APA 7 is the default; Harvard uses the official RMIT University
Harvard CSL style. Formatting runs locally with citeproc-js and requires no AI
credits. Reference and in-text outputs can each be copied.

The compatibility label is **Compatible with RMIT Easy Cite styles**. This is an
independent Tuturuuu tool. RMIT Easy Cite prose and examples are not included.
Tests use synthetic works. Style and engine attribution accompanies the tool.

## Source metadata

The shared internal API client calls `POST /api/v1/cite/lookup`. DOI metadata comes
from Crossref and ISBN metadata from Open Library. Webpage metadata fetches use
the exact HTTPS hosts `en.wikipedia.org`, `www.nature.com` and `arxiv.org`;
unsupported URLs require manual entry. Review
imported authors, titles and dates before copying a citation. Missing metadata
must be completed manually rather than inferred by AI.

Network lookup runs on the server without provider keys. Requests have bounded
input and streamed response sizes, an aggregate timeout and no automatic retry.
Redirects are rejected. Allowed webpage hosts resolve to public addresses and
connections pin the validated address. Upstream failures leave manual entry
available. Lookup does not create a saved citation library or upload a document.

Anonymous lookup is allowed. Before a lookup, an atomic shared-store reservation
enforces 10 requests per Cloudflare client IP per minute and 120 requests globally
per minute. Requests require the platform's authenticated Cloudflare-origin
proof before resolving the client IP from that proof or `CF-Connecting-IP`.
Other forwarding headers cannot substitute for origin authentication. Missing
proof, missing trusted client identity or an exhausted limit returns `429`;
unavailable budget storage returns `503`. Both include `Retry-After`. The lookup
fails closed and manual formatting remains available. Postgres counts each
minute separately and prunes older windows during reservations. The budget
stores a digest of the normalized IP. Lookup logs contain fixed categories
without source URLs or titles.

## Documents integration

<Note>
The Documents integration is undergoing qualification. Saved-library access
fails closed until its approved schema and typed storage adapter are available.
AI repair also requires an enabled credit-feature policy. The standalone helper
remains available independently of those services.
</Note>

Workspace Documents opts into the citation editor through its host adapter.
The toolbar, `/cite` followed by a space, and Mod+Alt+C open source capture and
the workspace library. Each inline citation stores its own versioned source
snapshot, locator and hide-author option. The References block derives its
entries from the document; changing APA 7 or Harvard reformats the whole list
and applies document-wide author/year disambiguation.

The shared editor preserves citation nodes even when insertion is disabled.
Deleting a library source does not delete a document's saved snapshot. A newer
library version requires an explicit update. Unknown snapshot versions remain
stored for recovery. Portable HTML and Markdown retain bounded, escaped citation
attributes; text-only output uses injected formatting or a readable fallback.

The portable `@tuturuuu/cite` package includes a canonical model, validation,
identifier deduplication and safe rich-output serializers. Documents formatting
uses the official APA style and an attributed Harvard derivative covering the
supported compatibility rules. The standalone three-type formatter retains its
official Harvard style. This is compatibility with tested cases, rather than a
claim that every RMIT source subtype has identical output. Authored code uses MIT;
the engine and style assets retain their separate CPAL and CC BY-SA notices.

## Capture and deterministic APIs

`POST /api/v1/cite/capture` adds arXiv and PubMed identifiers, DOI fallback through
OpenAlex, and explicit `title:` searches returning up to three review candidates.
It shares the anonymous lookup reservation. The only additional upstream host is
`api.openalex.org`; results never select a later request's host or path. Manual
completion remains available without inventing a source title.

A capture permits at most two upstream reads, a combined 256 KiB response budget,
and a five-second deadline. Grounding sessions share these limits across their
identifier checks and bypass the public cache. The default public capture cache
returns a miss. An injected store can cache validated DOI and ISBN bibliographic
fields for 24 hours.

Authenticated clients can use `POST /api/v1/cite/format` and `/validate` for server
parity without AI credits. They accept strict JSON up to 96 KiB. Formatting is
limited to 100 works, 200 citation occurrences and 10 sources per cluster. A shared
atomic budget admits 10 requests per verified actor per minute and 120 globally;
unavailable storage fails closed. These endpoints do not fetch source metadata.

## Saved library

Library CRUD lives under `/api/v1/workspaces/{wsId}/cite/library`; a bounded batch
read checks up to 50 linked items. Access requires workspace membership and
document-management permission. The workspace owns the library; creator
attribution can become empty when its account is deleted. Workspace deletion
removes the library, while separately saved document snapshots remain independent.

Create requests carry a client-generated item ID for retry identity. Duplicate
fingerprints resolve to the existing authorized source. Updates and deletes
require the expected version, so a stale editor cannot silently overwrite a
newer library item. Application validation and row policies enforce the same
workspace boundary. An unavailable schema is a service error, never an empty
library or an in-memory persistence substitute.

Editing bibliographic details keeps their capture origin but marks the edited
metadata as manual. An unchanged form retains its existing verification.

## AI repair

Repair is an explicit operation billed through the authenticated person's existing
personal credit pool and `cite_fix_ref` feature. The client cannot choose the
billing workspace, provider or model. Cost follows the platform's existing token
metering; deterministic formatting, validation and capture cost no AI credits.
The proposed source remains subject to review before it replaces document data.
The billing workspace must be personal, created by the actor and joined by that
actor. Thinking controls are explicit; unknown model capabilities fail before a
provider call. Combined output limits use a rate covering both text and reasoning.

Within an open editor session, repair retains its operation ID and original input
when a response is lost. Closing and reopening its panel preserves an unapplied
proposal; a full page reload does not preserve that client draft. Accepted
document snapshots and saved library items have separate persistence.
Postgres receipts bind each operation to the actor, billing pool, feature and
input. A pending settlement is reported as unknown. An invalid proposal can
still have settled token usage. An eligible retry can recover a confirmed
charge or dispatch an unclaimed checkpoint once through the database fence.
An ambiguous ledger read holds billing pending. A confirmed prior charge
prevents regeneration even if the proposal receipt is unavailable.

Authenticated repair reserves a separate grounding budget before calling the
model. It allows 30 operations per actor and 600 globally each minute. If the
budget is exhausted or unavailable, the repair returns `503` before generation
and billing. Registry failures during an admitted grounding session leave the
affected identifiers unverified. The model output remains billable and the
proposal still requires review.

### Operation lifetime and quotas

New repair operations use UUIDv7 identifiers no older than 15 minutes, with
one minute of allowed future clock skew. An operation that fails before storing
billable usage releases its pending receipt and active lease within 15 minutes.
The original binding can reopen that operation within one hour of its initial
claim. Other expired identifiers without a live receipt return `409`.

Only one repair can hold an actor's active lease. The running lease lasts two
minutes and an uncertain settlement holds it for up to 15 minutes. Settlement
receipts retain the proposal for one hour and omit raw input. After three
minutes, a retry can use a retained usage checkpoint if two ledger reads confirm
absence and it wins the same dispatch fence used by the initial request. An
unknown dispatch outcome retains the fence for the life of the receipt.
Credit-feature access and request allowances follow the existing plan policy.

The charge lookup uses validated workspace and actor UUIDs, operation metadata,
and an inclusive timestamp interval from the operation time minus two minutes
through lookup time plus one minute. New operations have a maximum 18-minute
lookup interval. A retained checkpoint permits a longer interval for billing
recovery. Actor or nonempty workspace mismatches cannot authorize a deduction.
Personal deductions may have an empty transaction `ws_id`. Qualification must
show the workspace/date and user/date indexes serving the query on seeded data.

Supported Gemini 2.5 Flash models disable thinking; supported Gemini 3 Flash
models request minimal thinking, and supported Gemini 3 Pro models request low
thinking. The explicit Anthropic and OpenAI sets disable thinking. Exact model
membership is defined by `citationThinkingControls`; unlisted models fail before
generation. The output cap is at most 8,192 tokens and can be lower according
to the personal credit balance. Production qualification checks the active
plan models against those sets instead of silently substituting a model.

## Scope and verification

The standalone helper supports books, journal articles and webpages. The Documents
slice adds common book, periodical, web, report, dataset, thesis, standard,
software, AI-generated and Indigenous-knowledge source families. Additional
styles, the full AI revision suite, native citation authoring, browser extensions
and Office add-ins are separate slices. Tuturuuu is the only product scope.

Regression coverage lives in `apps/web/src/lib/cite/format.test.ts`, the metadata
tests beside it, `apps/web/src/app/api/v1/cite/lookup/route.test.ts`, and the public
route tests. Release acceptance also requires the real web build and browser
checks at 390px and 1440px in light and dark themes, including lookup failures,
manual recovery, style switching and copy actions.

Portable formatter, validation, serializer and deduplication fixtures live in
`packages/cite/src`. Documents adapter/node and portable codec regressions cover
snapshot preservation, source identity and bibliography output. Database rollout
requires isolated full-schema policy, deletion, race and rollback checks, supported
type generation, Security review and explicit migration approval. Source checks
alone do not establish deployed or signed-in acceptance.
