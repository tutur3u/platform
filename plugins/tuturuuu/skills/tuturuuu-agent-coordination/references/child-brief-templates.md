# Child brief templates

Use these with the [worker contract](program-orchestration.md#worker-contract)
and [fleet procedures](program-orchestration.md#fleet-blockers-and-release-follow-through).

## Implementation

```text
Outcome and acceptance evidence:
Owner, parent, workspace, base and exclusive write paths:
Immutable inputs, holds, prohibited actions and remaining child budget:
Admitted checks and expected receipt:
latest-by YYYY-MM-DD HH:MM ICT
```

## Independent review

```text
Review outcome, exact head and required gates:
Parent, reviewer, review independence and scope:
Open findings and evidence needed for a verdict:
Last observed progress and verified reassignment owner:
latest-by YYYY-MM-DD HH:MM ICT
```

## Continuation or relay

```text
Remaining outcome, verified source state and current custody:
Unknown effects, native task/run IDs and successor acceptance:
Holds, blocker owner and next event:
latest-by YYYY-MM-DD HH:MM ICT
```

For each promised time, add the earliest realistic agent ETA and its basis,
observable success condition, accountable owner, and one-off T3 verification
schedule ID. The scheduled check reads live evidence once and escalates a miss.
Keep recurring watchers in place.
